Control your Zendure batteries directly via the home network, without the need for an internet connection or Zendure's cloud services.

This app supports the Zendure Solarflow Batteries and the Zendure energy meter.

Key features:
- Set input and output power
- Display state of charge
- Counts total charged and discharged energy (for calculating round trip efficiency)

The app supports the following models:
- P1 Meter
- 3CT-S Meter
- SolarFlow 800
- SolarFlow 800 Pro
- SolarFlow 800 Pro 2
- SolarFlow 800 Plus
- SolarFlow 1600 AC+
- SolarFlow 2400 AC
- SolarFlow 2400 AC+
- SolarFlow 2400 Pro
- SolarFlow 3000 Mix AC+
- SolarFlow 4000 Mix AC+
- SolarFlow 4000 Mix Pro
